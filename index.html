Dataset — DroneCrowd MOT (VisDrone, CVPR 2021)

All footage is 1920×1080, 25 fps, captured from a drone at varying altitudes across 70 outdoor scenes. Each sequence is 300 frames (~12 seconds). Download: Google Drive · Baidu Yun (code ml1u).

Train set: 15,347 unique tracked individuals · 147 people per frame on average · up to 455 in the densest scenes · IDs 100% persistent across all 300 frames per sequence.

Dataset Annotations vs. What the Scripts Produce

The raw dataset ships as images and annotation files — no visualizations. The annotation format differs between splits, and that difference directly affects what the rendering scripts can draw.

Train / Val — .mat head points

One file per frame. Contains a single (N, 3) array with columns x, y, person_id. Only the head centre is recorded — no bounding box. Scripts draw a filled circle at the head position.

Test — .xml bounding boxes

One file per sequence. Each <track id="N"> holds a <box> per frame with xtl, ytl, xbr, ybr, an outside flag, and an occluded flag. Ground-truth boxes — not model predictions.

What the rendering scripts add on top

  • Colour assignment — each person_id maps to a unique BGR colour from an evenly-spaced HSV palette, held constant across all frames.
  • Motion trail — the last 30 frame-centre positions drawn as a fading polyline, giving a visual sense of direction and speed.
  • ID label — numeric track ID printed above each annotation with a dark background for readability at high density.
  • HUD — frame counter, sequence ID, and visible / total counts burned into the top-left corner.

Next Steps

  • Integrate SAM 3 (Meta, Nov 2025) for pixel-level instance segmentation — text-prompted, unified detect + segment + track in a single forward pass.
  • Source a real live music event video from a static overhead angle — leading candidates: Festival of Lights Lyon (Zenodo, public), BBC Glastonbury webcam archive. Production plan: fixed camera on venue truss.
  • Evaluate YOLOv8 + ByteTrack (pretrained on VisDrone) as a faster real-time inference alternative to SAM 3.
  • Flow clustering to detect group movement patterns and crowd pressure buildup.
