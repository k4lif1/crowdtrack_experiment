Model Tracking — YOLOv8 + SAHI + ByteTrack

YOLOv8l fine-tuned on VisDrone, sliced via SAHI (640×640 tiles, 20% overlap) to handle tiny aerial people, tracked with ByteTrack. No ground-truth input. Runs on Apple Silicon MPS at ~2 fps.

  • SAHI — slices each 1920×1080 frame into overlapping tiles before detection; standard technique for small-object aerial inference.
  • YOLOv8l-VisDrone — mshamrai/yolov8l-visdrone, trained on the same benchmark as the footage.
  • ByteTrack — assigns consistent IDs across frames using IoU + Kalman filter motion prediction.
